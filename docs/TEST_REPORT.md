## 4. 缺陷台账

状态取值：Open / Confirmed / In Progress / **Fixed** / **Verified** / Won't Fix / Duplicate / Cannot Reproduce

### RT-001 同一行的确定性失败被无限重试
- **严重程度**：中（不误买，但会持续锤同一个按钮）
- **影响范围**：传统点击管线；触发条件为"弹窗验证反复不过"（价格歧义、图标不符）或"找不到购买/确认按钮"
- **复现步骤**：构造"弹窗内容与目标行不一致"或"价格出现两条相同期望值"的画面，观察点击次数
- **预期行为**：达到尝试上限后**暂时放弃该行**（刷新后重置）
- **实际行为（修复前）**：同一行被连续点击 60~180 次（压缩测试口径）
- **稳定复现**：是（模拟层）
- **当前状态**：**Fixed**（提交 \`8b1d34c\`：新增 \`BuyResult.VERIFY_FAIL\` + \`noteVerifyFailure()\` + \`Tuning.ROW_VERIFY_MAX_ATTEMPTS=3\`）
- **验证状态**：**Verified（模拟层）** —— 红队用例断言"出现『暂时放弃该行』日志"通过；**真机未验证**
- **规避方式**：无需（该缺陷不造成误买）
- **公开性**：可公开（不涉及攻击手法）

### RT-002 点击没生效却被标记为"该行已处理"（漏买）
- **严重程度**：高（直接漏买）
- **影响范围**：AI 点击管线（传统管线此前已修）
- **预期/实际**：预期"保持未决、下一轮重新决策"；修复前会标记已处理 → 该行被永久跳过
- **当前状态**：**Fixed**（提交 \`9b934cf\`）
- **验证状态**：**Verified（模拟层）** —— 漏买回归用例通过
- **真机验证**：未单独复现该场景

### RT-003 预算记账被"验证"门控 → 可无限消耗付费货币
- **严重程度**：高（真金白银）
- **影响范围**：AI 点击管线（默认管线）
- **预期/实际**：预期"点下确认即记账"；修复前只有验证通过才记账 → 预算上限永不触发
- **当前状态**：**Fixed**（提交 \`9b934cf\`）
- **验证状态**：**Verified（模拟层）** —— 钱路径用例断言"买到一件后 goldSpent 立即变化且闸门触发"
- **真机验证**：未做整夜挂机，**不能据此宣称零超支**

### RT-004 native 层 use-after-free（进程级崩溃）
- **严重程度**：高（唯一会让进程直接死的缺陷）
- **触发路径**：机器人运行中打开"装备评分"页 → 原生 OCR 模型被重复加载并释放
- **当前状态**：**Fixed**（提交 \`9b934cf\`：加载加互斥 + 幂等，加载完成才发布指针）
- **验证状态**：**Fixed，未验证** —— 修复后未在真机上复现原触发路径
- **需进一步测试**

### RT-005 模型加载失败无法被检测
- **当前状态**：**Fixed**（提交 \`9b934cf\`）
- **验证状态**：**Fixed，未验证**（模拟层未覆盖 native 加载失败路径）

### RT-006 Shizuku 一键授权通道失效
- **当前状态**：**Fixed**（提交 \`9b934cf\`：补 provider 声明 + R8 keep）
- **验证状态**：**Verified（真机）** —— \`dumpsys\` 可见该 provider 已注册

### RT-007 静默改写全设备级无障碍安全开关
- **严重程度**：中（越权修改系统设置）
- **当前状态**：**Fixed**（提交 \`9b934cf\`：删除全局写入，改为受设置项显式授权）
- **验证状态**：**Verified（代码 + 真机行为）**

### RT-008 WebDAV 同步恒失败（HTTP 409）
- **严重程度**：中（功能不可用，不造成数据损坏）
- **根因**：云端目录从未创建；服务端对不存在的集合返回 409（而非 404）
- **当前状态**：**Fixed**（提交 \`4776b21\`：分层探测 + MKCOL 自动建目录 + PROPFIND Depth:0）
- **验证状态**：**Verified（真机 + 真实云服务）** —— 项目作者实测上传成功

### RT-009 应用更新后无障碍启用状态被系统清掉
- **性质**：**平台行为**，非本应用缺陷
- **现象**：覆盖安装后应用内显示"无障碍服务未开启"，需重新启用
- **当前状态**：**Won't Fix**（Android 安全设计）
- **规避方式**：更新后重新开启一次无障碍服务
- **公开性**：应写入 README 的"升级注意事项"

### RT-010 两个主题文件存在逐字重复（可维护性）
- **严重程度**：低（维护风险；历史上曾因重复导致 BA 主题漏掉风险确认闸门）
- **当前状态**：**部分修复**（提交 \`7b40638\`：阶段映射、图片选择器、风险弹窗已抽到 \`ui/UiCommon.kt\`；逐字重复 12 块/145 行 → 8 块/99 行）
- **未修复部分**：剩余重复都夹在各自布局内部，抽取需重构两套布局树，且需要真机逐屏视觉验证
- **状态**：**Won't Fix（本版本）**，登记为已知技术债

### RT-011 缺少持续集成
- **当前状态**：**In Progress** —— 已提供 GitHub Actions 工作流（构建 + 单测 + lint）；尚未在真实仓库运行过

### RT-012 识别准确率受模型与画面条件限制
- **性质**：**已知限制**
- **说明**：识别依赖 YOLO 模型 + OCR；极端分辨率、UI 缩放、非典型商店布局、遮挡或动画中间帧都可能降低召回
- **当前状态**：**Known Issue**（不修复；持续通过回归台样本迭代）
- **公开性**：写入 README「已知问题」

### RT-013 自动化操作可能违反游戏服务条款
- **性质**：**已知风险**
- **说明**：应用内置拟人化操作，但**无法保证不被判定为违规**，存在账号风险
- **当前状态**：**Known Issue**（不修复；首次启动要求用户确认风险）
- **公开性**：必须写入 README 顶部显著位置

### RT-014 高权限能力面（无障碍 + 安全设置写入）
- **性质**：**设计取舍**
- **说明**：应用需要无障碍服务（截图与手势）与可选的 \`WRITE_SECURE_SETTINGS\`（一键开启无障碍，需 adb 授权）
- **当前状态**：**Accepted**（已在 README「安全与隐私」说明用途与边界）
