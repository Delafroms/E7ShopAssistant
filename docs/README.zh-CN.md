# E7SA — E7 Shop Assistant（E7 商店助手）

> **风险提示**：本工具通过无障碍服务自动操作《第七史诗》，**可能违反游戏服务条款，存在账号风险**。
> 是否使用、以及由此产生的任何后果，由使用者自行承担。本项目与 Smilegate 无任何关联。

E7SA 是一个面向《第七史诗》（Epic Seven）**神秘商店**的辅助工具：截图 → 识别 → 决策 → 点击，
自动购买目标商品并在无可买目标时刷新商店。

- 语言：[简体中文](docs/README.zh-CN.md) · [English](docs/README.en.md) · [日本語](docs/README.ja.md) · [한국어](docs/README.ko.md)

## 项目简介

神秘商店每次刷新只有 6 格，目标商品出现率低（单格誓约书签约 0.66%、神秘奖牌约 0.17%）。
人工反复刷新成本高，因此本项目把"看画面 → 判断 → 点击"这条链路自动化，目标只有三条：

1. **零漏买**——识别到可买的目标就一定要买到；
2. **零误买**——证据不足时宁可不买，也不点错；
3. **预算可控**——金币与天空石（付费货币）都有硬闸门。

**开发阶段**：v1.0.0 为首个公开版本，属于**个人项目**，不是商业产品。
**测试完整性**：单元测试与对抗性测试在模拟层通过；真机验证仅覆盖安装、启动、界面与云同步；
**长时间连续运行尚未验证**（详见「测试状态」）。

## 核心功能（已实现）

- **双识别引擎**：YOLO 视觉识别 / 传统识图（由「购买」按钮文本推导行结构 + 图标区颜色签名 + 文本校验）
- **双点击管线**：AI 点击（YOLO 为眼睛 + 独立决策状态机）与传统点击（文本锚点），两条管线互不回退
- **预算闸门**：金币上限、天空石上限、书签/奖牌持有上限；达到上限即停止
- **挂机省电**：运行期间保持屏幕常亮，任务完成或达上限后可按设置自动熄屏
- **悬浮任务面板**：状态、阶段、统计、事件日志、开始/暂停/停止（可拖拽）
- **记录与统计**：会话历史、累计购买与消耗
- **诊断工具**：原始帧采集、识别回归台（长按版本号触发）
- **三套主题**（Steam 深色卡片 / Steam OLED 纯黑 / Blue Archive 明亮学院）与中英文界面
- **可选云同步**：WebDAV（用户自备服务器与凭据），不配置则不联网

*Experimental（可用但仍在验证）*：睡眠模式（全帧完整识别，更慢更稳）、自定义背景图与顶部标识、
主题切换动画函数选择。

## 技术架构

```
截图（无障碍服务）
  → 预处理（缩放/裁剪，分辨率无关的采样窗）
  → 场景判定（商店列表 / 购买弹窗 / 刷新弹窗 / 网络异常 / 其他）
  → 候选检测（YOLO 图标框 ∪ OCR 商品名行）
  → 特征提取（行结构由「购买」按钮行距推导、图标颜色签名）
  → OCR（PP-OCRv5）
  → 多信号融合（文本 + 图标旁证 + 价格唯一匹配）
  → 过滤（售罄、已处理行、类型开关）
  → 决策（BotEngine 传统管线 / AiBotEngine AI 管线）
  → 最终点击闸门（ClickGate：坐标合法 + 未停止）→ 手势执行
```

- **识别与决策分层**：识别层只回答"看见了什么"，决策层决定"做什么"，设备层只负责"取屏幕、按屏幕"。
- **两条点击管线完全独立**：AI 管线在无法确定时**明确报告并保持不动，绝不回退到传统点击**。
- **ACTION → COMMIT**：任何改变内部状态的动作（购买、刷新、预算扣减）在**动作发生的那一刻**记账，
  验证只影响后续决策。
- 原生层（C++）负责 ncnn 推理与图像处理；模型由 `assets/e7sa_yolo.ncnn.meta` 自描述（换模型无需改代码）。

## 安装与使用

**环境要求**：Android 11（API 30）及以上；arm64-v8a 或 armeabi-v7a。
仅在 OnePlus PLR110 / Android 16 / ColorOS 上完成真机测试，其它机型与厂商 ROM 未经验证。

1. 安装 APK（来自本仓库 Releases 页面）。
2. 打开应用 → 按提示开启**无障碍服务**（必需，用于截图与手势）。
3. 可选：通过 adb 授予 `WRITE_SECURE_SETTINGS` 以使用"一键开启无障碍"通道：
   `adb shell pm grant com.e7.shop android.permission.WRITE_SECURE_SETTINGS`
4. 首次使用需在弹窗中**确认风险**，然后进入《第七史诗》的神秘商店界面，点「开始」。
5. 建议先设置**金币消耗上限**与**天空石预算上限**（0 = 不限制）。

**停止**：点悬浮窗或应用内的「停止」。任何时刻重新点「开始」都会结束上一轮、清空本轮统计并从当前画面恢复。

**异常恢复**：若长时间无动作，先确认无障碍服务仍在运行（系统可能在应用更新后关闭它）；
应用内置"点击无效 → 退避重试""残留弹窗 → 发送返回键关闭"等自愈逻辑。

**提交问题**：见下方「Bug 报告」。

## 安全与隐私

| 项目 | 说明 |
|---|---|
| 权限用途 | 无障碍服务：截图与模拟点击；悬浮窗：任务面板；通知：保活提示；`WRITE_SECURE_SETTINGS`（可选）：一键开启无障碍；Shizuku（可选）：备用授权通道 |
| 截图与识别数据 | **仅在设备本地处理**，不写入网络、不上传 |
| 是否联网 | **仅在用户主动配置 WebDAV 同步时联网**；不配置则不产生任何网络请求；无遥测、无统计 SDK |
| 保存的数据 | 应用配置（SharedPreferences）、运行日志与统计（应用私有目录）；WebDAV 账号与应用密码单独存放并**排除系统备份与设备迁移** |
| 日志 | 运行日志可能包含识别到的界面文本（游戏内文本）；提交日志前请自行检查是否含个人信息 |
| 清理数据 | 卸载应用即清除全部本地数据；设置页可清理统计与日志 |
| 测试版本风险 | 本版本为**首个公开版本**，长时间运行表现尚未验证；隐私行为可能随版本变化，请以对应版本的 Release 说明为准 |

## 已知问题（Known Issues）

完整台账见 [docs/TEST_REPORT.md](docs/TEST_REPORT.md)（RT-001 ~ RT-014）。

- **RT-004 / RT-005**：原生层崩溃与模型加载检测已修复，但**未在真机上复现验证**。

- **RT-014**：需要无障碍服务；一键授权通道需要较高权限。
