## 三、native 加固

- `get_rotate_crop_image`：`rw<=0` 的退化框（minAreaRect 对近似共线轮廓）会让 `rh*48/0=inf` → warpAffine 抛异常穿透 JNI = std::terminate。**现在直接挡掉并返回空 Mat**，`recognize` 增加空 roi 早退。
- `recognize()` 里在 OpenMP 并行区写全局 `cv::setNumThreads(1)` → 删除（JNI_OnLoad 已设过）。
- 逐像素诊断扫描（640×640≈41 万次 `pred.at<uchar>`）从**生产热路径**移到编译期开关 `kDetDiag`（默认 false，常量折叠后零开销）。
- `JNI_OnLoad` 的 libomp setenv 补注为"历史遗留 + 当前构建已用 simpleomp"，终止注释与构建现状不符的误导。

## 四、工程化

- **lint 门禁真正建立**：`lint { baseline = file("lint-baseline.xml"); abortOnError = true }`，生成基线冻结 112 条存量问题；**不再需要 `-x lint`**。本轮它立刻抓到我自己引入的一处 SuspiciousIndentation —— 门禁已在工作。
- `proguard-rules.pro`：`-keep class okhttp3.** { *; }` 收窄为 6 个实际直接引用的类型（R8 重新对整库生效）。
- 删除死字段 `RunLog.enabled`（注释写"玩家可在设置里关掉"，实际无人赋值、设置里也没有开关 —— 代码里的假开关；日志量已由 level 控制）。
- Kotlin 弃用警告（SCREEN_DIM_WAKE_LOCK）显式 `@Suppress` 并说明理由。
- **死资源清理**：零引用字符串 80 条（values + values-zh 同步）、零引用 drawable 17 个，全部删除。

## 六、本轮**未做**的项（诚实标注）

1. **主题文件 41% 逐字重复**（ThemeSteam/ThemeBlueArchive）——属结构性重构（两个文件各 ~1000 行），风险高于收益，需要单独立项。
2. **两个决策状态机（BotEngine / AiBotEngine FSM）仍零测试** —— 需要可注入的假 Host/假时钟脚手架，是独立一轮的工作量。
3. **魔数收敛到 Tuning**（17 处 sleep 字面量）：纯重构、行为不变，但 17 处逐一手改的回归风险不小，留到状态机测试补齐后再做（那时有安全网）。
4. **release 签名密钥**：换 key 会导致无法覆盖升级（需卸载重装、丢数据），且群友侧要重新分发 —— 属**用户决策**，未擅自改。
5. **versionCode/versionName 未升**：与上一轮"仍属 V1、不升版本号"的口径一致（若要升，说一声即可）。
6. **MIN_ROW_TOL=40f** 评估后**不动**：它是行匹配容差的下限，行容差本身已由行距推导（`rowPitch×0.45`，实测过的活锁根因）；改成分辨率相关值需要改签名与全部调用点，风险 > 收益。

## 七、需要你手动确认一次的地方

- **WebDAV 同步**：本轮收窄了 OkHttp 的 proguard keep 并加了下载上限。代码路径未被单测覆盖 → 请在设置页点一次「测试连接」+「上传/下载」，确认云同步仍正常（如果失败，把 keep 规则恢复成 `okhttp3.**` 即可，一行的事）。
- **无障碍包名限定**：若你玩的区服包名不是 `com.stove.epic7.google`，事件订阅会为空 —— 但**截图与点击不受影响**（本服务从不使用无障碍事件），功能等价。
