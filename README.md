# E7SA — E7 Shop Assistant（E7 商店助手）

面向《第七史诗》（Epic Seven）**神秘商店**的辅助工具：截图 → 识别 → 决策 → 点击。

> **风险提示**：本工具通过无障碍服务自动操作游戏，**可能违反游戏服务条款，存在账号风险**。
> 使用与否及后果由使用者自行承担；本项目与 Smilegate 无任何关联。
