# E7SA — E7 Shop Assistant（E7 商店助手）

[![Issues](https://img.shields.io/badge/Issues-welcome-blue?logo=github)](../../issues) [![Releases](https://img.shields.io/badge/Releases-latest-green?logo=github)](../../releases)

面向《第七史诗》（Epic Seven）**神秘商店**的辅助工具：截图 → 识别 → 决策 → 点击，
自动购买目标商品（誓约书签 / 神秘奖牌），无可买目标时刷新商店。

## 这是什么

神秘商店每次刷新 6 格，目标商品出现率很低（誓约书签单格约 0.66%、神秘奖牌约 0.17%），
刷新一次要花 3 天空石。人工盯着屏幕反复刷新既枯燥又容易错过，E7SA 把这条链路自动化，
设计目标只有三条：**零漏买**（识别到就一定要买到）、**零误买**（证据不足宁可不买）、**预算可控**（金币与天空石都有硬闸门）。

## 主要功能

- **双识别引擎**：YOLO 视觉识别 / 传统识图（行结构由「购买」按钮行距推导 + 图标颜色签名）
- **双点击管线**：AI 点击（YOLO 为眼睛 + 独立状态机）与传统点击（文本锚点），互不回退
- **预算闸门**：金币上限、天空石上限、书签/奖牌持有上限
- **悬浮任务面板**：状态球 + 阶段 + 统计 + 事件日志 + 开始/暂停/停止
- **四套主题** + 中英文界面；可选 WebDAV 云同步（不配置则不联网）
- **诊断工具**：原始帧采集、识别回归台（长按版本号触发）
